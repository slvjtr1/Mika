## What it is
A photo and short-video social platform with profiles, a feed, search and Explore, posts, Reels and Messages.

## Pages and URLs
Home is `https://www.instagram.com/`. A profile is `/<username>/`.

## Features
- **Profile**: username, bio, post count, followers, following, verified badge and private state. Display names can repeat; only the username is unique.
- **Posts and Reels**: author, caption, posting time, like and comment counts. Reach them by searching an account, a hashtag or a post link.

## Known behaviour
A private account's page and a rate-limited page both look like empty content.
