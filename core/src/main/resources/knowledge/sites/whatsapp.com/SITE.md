## What it is
A worldwide messaging service. The web version `web.whatsapp.com` shares one account with the phone and desktop apps.

## Pages and URLs
The web version is at `https://web.whatsapp.com/`. When not linked, the page shows a QR code to scan with "Linked devices" in WhatsApp on the phone. After signing in, the left side has the conversation list, search and the new chat button; the right side is the chat window. The UI language follows the browser.

## Features
- **Read**: the conversation list shows titles and the last message; open a conversation to see the text and times; in groups you can see who said what.
- **Send**: in an existing conversation, type in the input box at the bottom and send; start a new chat from New chat or by searching for a contact.

## Known behaviour
Linking a device uses a QR code, which is a different check from a phone number verification code. With newer linking, the phone doesn't have to stay online.
