## What it is
Telegram is a messaging app, package `org.telegram.messenger`. Website knowledge is under `telegram.org`.

## Screens
There are Chats (the conversation list), Contacts and a new message entry; for a new message you can pick someone from contacts or search. The page it opens on is not always Chats.

## Features
- **Read messages**: find the target in the conversation list and open it, scroll to see history; each message has a sender and a time. Groups, channels and contacts are different kinds of objects.
- **Send messages**: type in an existing conversation, or choose a recipient from Contacts or the new message entry. After sending, a new message bubble appears in the conversation. The contact page shows the contact's profile.
